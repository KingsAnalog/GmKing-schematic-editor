Schematic Editor Help

Place components and shapes

Open Library to browse symbols and shapes. Press I to search for a component. Select an item and click the canvas to place it. Select an item on the canvas to edit its settings in Properties.

Connect and label nets

Press W and click a pin, wire end, or grid point to start a wire. Click to add bends. Click a pin or press Enter to finish. Press L, enter a net name, and click the wire or junction to place the label.

Arrange the drawing

Use Layers to show, hide, or lock layers. Use Properties → Layer to move a selected object to a different layer. Press R to rotate, Ctrl+R to mirror across X, or Shift+R to mirror across Y.

Save and reopen a schematic

Workspace tabs are saved in this browser. Use the tab strip to import or paste schematic JSON into a new tab. Export JSON to keep an editable backup or export SVG or PNG to share an image.

Editor options

The gear opens Options, which also contains the current schematic's symbol template. Choose Wire crossings → Plain for straight crossings or Hop to show a bridge where wires cross without joining. Dots mark actual connections in either mode.

Default text font sets the font for the current schematic's notes and net labels. Select an individual note or net label and choose Properties → Font to override it or return to Document default. These settings are included in schematic JSON and used for image export.

Schematic Editor 使用说明

放置元件和图形

打开器件库浏览符号和图形，或按 I 搜索元件。选择项目后点击画布放置。在画布上选中对象后，可以在属性面板中编辑。

连接导线并命名网络

按 W，点击引脚、导线端点或网格点开始绘制。点击画布添加拐点，点击引脚或按 Enter 结束。按 L 输入网络名，再点击导线或连接点放置标签。

整理图纸

在图层中管理图层的可见性和锁定状态，通过属性 → 图层调整所选对象所属的图层。按 R 旋转，按 Ctrl+R 沿 X 轴镜像，按 Shift+R 沿 Y 轴镜像。

保存与重新打开图纸

工作区标签页保存在当前浏览器中。通过标签栏导入或粘贴电路 JSON，可在新标签页打开图纸。导出 JSON 可保留可编辑的备份，导出 SVG 或 PNG 可分享图像。

编辑器选项

点击齿轮打开选项，可设置当前电路的符号模板。在 Wire crossings 中选择直线交叉（Plain）或跨线桥（Hop）。两种模式都用圆点表示真实连接。

通过 Default text font 选择当前图纸的注释和网络标签默认字体。在属性 → 字体中可覆盖单个对象的字体，或恢复为文档默认值。这些设置随电路 JSON 保存，并用于图像导出。
